# Portfolio Website

A distinctive, production-grade portfolio site built as a single-page frontend.

## What to customize

- Replace `Your Name` in `index.html`
- Update `City, Country`, timezone, and contact links
- Swap the accomplishment cards with your real wins
- Adjust the timeline entries to match your history
- Replace the placeholder email address

## Run

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- This repository contains `Resume.pdf` and an extracted `Resume.txt` used to
	populate the site content. To update content, edit `index.html` or regenerate
	from a new resume PDF.

### Preview locally

Run a simple static server (Python):

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
